**I4 — duplicate vehicle-type slug is rejected**  
The UNIQUE(slug) constraint must fire (23505) so the route can map it to 409.

**I5 — region → city → tourist-spot chain inserts and resolves names**  
The geography hierarchy inserts cleanly and each level resolves its parent name.

**I6 — createCity with a bad regionId is rejected**  
cities.region_id FK must fire (23503).

**I7 — signup: second account with the same email is rejected**  
users.email UNIQUE must fire (23505) even if the app-level pre-check is bypassed by a race.

**I8 — addPackageStop with a bad touristSpotId is rejected**  
package_stops.tourist_spot_id FK must fire (23503).

**U1 — partial update touches only the given column and stamps the audit trail**  
updateVehicleType({title}) leaves slug/description alone, sets updated_by, and the updated_at trigger is installed and fires.

**U2 — updating a slug to one already taken is rejected**  
updateVehicleType must surface the UNIQUE(slug) violation (23505), not a generic failure.

**U4 — updateVehicle rewrites JSONB features correctly**  
features passed to the generic partial-update path must land as a JSONB array, not a quoted string.

**U5 — updating a non-existent row returns null (no throw)**

**D4 — a city with an active tourist-spot cannot be deleted**  
Same guard, next level down.

**D6 — deleting a package also soft-deletes its stops**  
Stops are part of the package (composition) — they must not be left behind pointing at a deleted package.
